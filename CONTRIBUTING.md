# Contributing

Thanks for helping improve this learning exercise.

Keep changes focused on the documented lesson. Preserve the intended starter state, do not commit completed exercise answers, and do not add dependencies unless the exercise explicitly requires them.

Before submitting a change:

1. Run the verification commands in `README.md`.
2. Check that no generated files, credentials, or private data are included.
3. Describe what changed and include the verification result.

Use an issue to propose a larger change before investing in an implementation.
